# Semantic HTML Seminar

A beginner's guide to writing HTML that means something.

## Files

- `demo.html` — the example page shown in dev tools during the seminar
- `exercise.html` — the div soup page to rewrite
- `solution.html` — the completed exercise (spoilers — attempt the exercise first!)
- `reference.html` — a cheat sheet of every semantic tag covered in the seminar
